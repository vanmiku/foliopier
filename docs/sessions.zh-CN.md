# 在文章旁继续项目对话

[English](sessions.md)

在设置中开启「显示终端会话」即可阅读项目近期对话；「允许向已连接的 Agent 发送消息」是独立开关。新安装默认均关闭。开启查看后，能够访问该工作台的设备（包括已授权的局域网设备）将能阅读项目原始对话，而不只是已经发布的文档。

尚未开启查看时，新功能引导会在当前浏览器提示一次；「去设置开启」直达终端会话设置，查看和发送仍由你分别开启。设置里的「了解会话功能」可以再次打开引导。阅读目录或关闭手机会话面板时暂停刷新，重新打开后恢复同步。

每篇文章右侧使用同一排「目录 / Codex / Claude Code」tab。规范项目目录相同的文章，在当前浏览器标签页共享 Agent 和手动选择的会话；不同位置的同名文件夹不会串会话。Git worktree 会归到主项目目录。从当前项目文件夹重新发布文章可更新它的目录关联；目录丢失或不明确时会显示原因，不会猜测另一个目录。

Codex 的续接日志可能带额外的 ID 后缀；mydash 按日志头中的原会话 ID 识别，并选取最新有效日志。后台会话通过只读路由定位，再验证原 App 的会话归属和发送能力。App 正在运行不代表所有历史会话都有连接；若提示此会话还未接入，请在部署 mydash 的电脑上打开这条会话，随后点「重试连接」，草稿会保留。

## 0.2.1 的连接能力

| 连接方式 | 阅读近期消息 | 发文字 | 发图片 | 送达与回复跟踪 |
|---|---|---|---|---|
| Codex App 本地连接 | 支持 | 发到已打开的原会话 | PNG、JPEG、WebP、GIF | 每会话最多 5 条未完成消息，忙碌时排队，服务重启后恢复 |
| Codex CLI 的已验证 tmux 终端 | 支持 | 输入区确认空白时可发 | 暂不支持 | 匹配用户消息收据及任务完成边界，不自动重发 |
| Claude Code 的已验证 tmux 终端 | 支持 | 输入区确认空白时可发 | 暂不支持 | 匹配原会话收据和回复完成边界，不自动重发 |
| 开启 Remote Control 的 Claude App Code 会话 | 连接后支持 | 空闲、已连接且账号允许时可发 | mydash 0.2.1 暂不支持 | 使用同一个 Remote Control 会话，将 client 消息与后续 worker 回复及结果关联 |

工作台本身支持 macOS、Linux 和 Windows。Codex App 直连目前要求私有本地 Unix socket，尚未实现 Windows 直连；CLI 自动匹配 tmux 进程需要 macOS 或 Linux。Claude App Code 按其本地账号会话目录发现，排除云端、远程、SSH 和 WSL 会话。这些连接适配器属于需要主动开启的预览功能，平台覆盖小于工作台本身。

Codex 适配器校验 App 本地协议版本（stream 11、start-turn 2）、本机进程所有权和真实项目目录；不兼容时会暂停发送。它不会启动另一份 CLI，也不会更改原 Agent 的权限、模型或沙盒。

## 如何连接与发送

1. 在原 Agent 中打开项目并保持会话运行。Codex 的旧会话不要求此前安装过 mydash hook；大量历史会逐步建立索引，已知会话 ID 可以直接查找。
2. Codex App 请打开原本的本地会话。Claude App 的 Code 会话请打开会话详情，开启 **Remote Control** 并保持连接；`/remote-control` 命令用于支持它的 CLI 环境，在 App 中可能不可用。请使用原有已登录的 Claude 账号。账号资格、组织策略、Trusted Devices 和用量限制继续生效，详见 [Anthropic 官方 Remote Control 说明](https://code.claude.com/docs/en/remote-control)。
3. 命令行请在 tmux 中运行。mydash 会校验进程启动时间、会话、TTY 和 pane。终端有草稿、待审批、近期键盘输入或无法识别的界面时会拒绝发送，不会向任意 shell 输入内容。
4. 选择 Agent，顶部始终显示会话标题及自动跟随/手动选择状态。点击标题打开站内会话列表，可搜索标题、摘要或编号；每条显示工作状态、项目最新标记、更新时间、最近消息摘要、连接来源和短编号。正在编辑、等待回复或回看历史时，新会话只提示，不会悄悄替换目标。
5. 输入问题，默认只发你写的正文。文章选段需要主动添加。Codex App 连接下可选「添加图片」或直接粘贴，每次最多 4 张、每张 5 MB；也可以只发图片。

部署机器本机与可信 Tailnet 连接可以发送。普通已授权的 LAN 浏览器只能查看对话，不能发送、上传或读取附件文件、管理发送队列或修改会话设置。

## 排队、报错与恢复

每条未完成消息都有自己的状态和操作入口。Codex App 尚未派发的消息会在 30 分钟后过期，避免很久之后才意外发送。尚未派发的 Codex App 消息可以取消；送达状态不确定时，先核对原 App，再点「已核对 Codex App，停止等待」，解除队列阻塞。这不会停止 Codex 中已经执行的工作。

Claude Remote Control 目前仅在空闲时接受 mydash 消息，不在工作中或待审批时排队，避免把上一轮的完成误认为新消息的回复。Claude App 可能把 Remote Control 消息标为来自其他会话，并继续应用原有权限保护。账号用量错误会显示在对话中并结束回复等待，不代表消息没有送达。

「已送达」与「已完成回复」分别跟踪。处理中报错不代表没发到；Codex App 对同一任务的后续重试会继续跟踪，不会重复提交用户消息。送达不确定时不自动重发。需要确认的事项仍遵守原 Agent 已有的审批流程。

无法连接时，可以在文章页保留问题草稿；「记录问题」不会代你发送。草稿、选段、附件引用和阅读位置按文章版本、文件、Agent 和会话隔离，存于当前浏览器标签页；隐私模式或清除浏览器存储可能使其消失。当前展示有范围限制的近期记录，省略工具输出和内部推理；本版本尚无完整历史加载或全文会话搜索。

## 图片空间管理

「设置 → 会话图片」显示本地用量并提供清理入口。从草稿移除未使用的图片会释放对应上传。未引用的上传在上传或最近读取后的 30 天过期；再次上传时自动回收，也可在设置里主动清理。

「清理未使用的上传图片」可能移除尚未发送的草稿附件，之后需重新添加；已排队、处理中和已发送的附件引用会保留。「删除已完成消息的附件」需明确确认，还会删除用于历史查看的本地图片，因此较早会话中的相关图片可能无法打开；排队中和处理中的附件仍受到保护。上传存储上限为 256 MB（包括元数据），数量约 1024 对图片与元数据文件。图片清理不删除用于防重复发送和历史状态的本地文字记录。

## 本机入口与故障排查

请在部署机器上收藏 `http://127.0.0.1:4870/`；端口不同可运行 `mydash url --local` 获取。mydash 服务正常运行时，该入口不依赖 Tailscale。其他设备仍需 Tailscale 或已授权 LAN 连接。Tailscale 网址已经整页无法加载时，无法显示网页内提示，应直接使用收藏的本机入口；已打开的页面断线会显示恢复提示，不会重载未发送的问题。

Claude 登录错误请在原客户端重新登录；用量限制、Trusted Devices 等要求也应在 Claude 中处理，mydash 不会修改这些限制。不确定是否送达时，先核对原会话再重试。App 协议不兼容时，更新 mydash 或继续在原 App 中使用。

信任边界、凭据处理和数据保留详见 [SECURITY.md](../SECURITY.md)。macOS 的 GUI 凭据辅助进程仅为后台服务读取现有已解锁登录钥匙串，`mydash uninstall` 会移除它。
