# 临时分享文档

分享者需要运行 FolioPier AI 和支持 Funnel 的 Tailscale。访客不需要安装软件、注册账号或连接 Tailscale。

## 首次开启

1. 打开 FolioPier AI 的“设置 → 互联网文档分享”，点击“开启互联网分享”。
2. 按页面提示完成 Tailscale 登录与 Funnel 授权。组织管理员可能需要允许该设备；不要用别人的账户替换现有账户。
3. 授权后回到 FolioPier AI，再点一次“开启互联网分享”。当前 0.3.0 的“重新检测”只检查状态，不会重试开启。页面分别显示本机服务、Funnel 配置、PDF 组件和外网验证状态。
4. 从文章进入设置时，点击“返回文档，继续分享”可恢复原来的选择。

更新后无法开启时，见[网页、命令行与后台授权的详细步骤](sharing-setup.zh-CN.md)。

Funnel 使用专用的 8443 或 10000 HTTPS 端口；FolioPier AI 不覆盖其他应用的路由，也不把工作台的私有 443 入口改成公网。首次 DNS 生效可能需要等待。本机检查成功不代表外网已通，可以用手机关闭 Wi-Fi 后测试。

PDF 下载需要运行 FolioPier AI 的电脑已有 Chrome、Chromium 或 Edge。组件缺失时，分享阅读仍可用，PDF 按钮会说明原因；按设置页链接安装浏览器后再检测。

## 创建与更新

文章右上角点击“分享”。主 Markdown 默认选中，其余文件由你勾选；先用“以访客身份预览”检查正文和附件是否适合公开，再生成链接与 8 位访问码。访问码只在创建或重置时显示，程序只保存加盐哈希。复制完整分享信息，或分别复制链接与访问码。

默认 24 小时到期，也可选 1 小时、7 天或自定义，最长 30 天。默认跟随后续发布的版本；固定版本模式保留创建时所看的版本。未经发布的磁盘修改不会公开。跟随更新的新资源路径需要你确认，等待期间访客继续阅读上一版。

访客可以切换共享文件、阅读表格和图示、下载允许的 PDF，以及留下私密留言。HTML 是隔离的静态预览，不运行附件中的脚本。Agent 会话、内部批注、审批答案和工作台操作不属于共享界面。仍需自行审查文档正文，敏感内容扫描不能保证发现所有不宜公开的信息。

## 留言与停止

文章“分享 → 管理分享”和设置页可查看留言、文件与版本，也能标为已处理。`foliopier feedback` 将其标为外部、未经信任的反馈；留言不会直接发送给 Agent 或触发执行。访客仅能看见当前浏览器自己的留言。

可以延长时间、重置访问码、调整选中文件，或停止单条分享。重置访问码会使已有访客登录失效。归档文章不会停止分享，页面会提示活动链接。关闭设置页的总开关会撤销全部旧分享；再次开启后需要重新创建链接。下载后保存的内容无法收回。

分享期间主机需要保持在线。机器睡眠、断网或 Tailscale 不可用时，没有云端副本继续提供内容。设备域名会出现在公开证书记录中；文档正文不会因为申请证书而进入证书记录。

参考：[Tailscale Funnel 官方说明](https://tailscale.com/docs/features/tailscale-funnel)。
